# Valentine & 1st Anniversary Static Site

This is a small static single-page site (pure HTML/CSS/JS) designed as a romantic Valentine's Day + 1st Anniversary site with five pages/sections.

How to use
- Open `index.html` in a browser.
- Replace `assets/bouquet.svg` and `assets/placeholder.svg` with your own images.
- Update the password and anniversary date in `script.js` (`CORRECT_PASSWORD` and `ANNIV_DATE`).
- Replace `VIDEO_ID` in `index.html` iframe src with the desired YouTube video ID.

Files
- `index.html` - main document with 5 sections
- `styles.css` - styling and animations
- `script.js` - interactions: navigation, password, counter, modal, hearts
- `assets/` - placeholder images

Notes
- No backend required.
- Works on desktop & mobile; tested visually. For autoplay behavior, modern browsers may require the video to be muted.
